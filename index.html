ChatDeck puts ChatGPT and Claude side by side, groups conversations by project, and keeps a terminal one tab away. A small desktop app, no browser clutter.

Built for working, not just chatting

Everything you keep open in a dozen browser tabs, arranged in one window.

Side-by-side panes

Split the window and compare answers, or keep a reference chat open while you work in another.

Tab groups per project

Keep each project's conversations together and switch between them in one click.

Terminal tabs

Open a shell next to your chats: PowerShell on Windows, zsh on Mac.

ChatGPT and Claude

Use either or both, with your own accounts. Your workspace is restored when you reopen it.

Install in a minute

ChatDeck is new and not code-signed yet, so your computer asks once before the first launch.

  1. Download and run the installerNo administrator rights needed. It installs for you alone.
  2. If Windows says "Windows protected your PC"Choose More info, then Run anyway.
  3. Sign in and you are setNew versions install from Settings inside the app.
  1. Open the dmg and drag ChatDeck to ApplicationsOne download for Apple Silicon and Intel Macs.
  2. Allow the first launchmacOS blocks it once: open System Settings › Privacy & Security and choose Open Anyway. If it says the app "is damaged", run xattr -dr com.apple.quarantine /Applications/ChatDeck.app in Terminal.
  3. Sign in and you are setTo update, download the latest dmg from this page.
