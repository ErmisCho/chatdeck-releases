See it in action

Built for working, not just chatting

Everything you used to keep in a dozen browser tabs, arranged in one window that remembers how you left it.

Split, resize, compare

Put chats next to each other and drag the dividers to fit. Compare answers, or keep a reference open while you work in another.

  • As many panes as your screen has room for
  • Drag a tab onto a pane to move it there
  • The layout is restored exactly on restart

Tabs that behave like tabs

Open a new chat in any pane, switch with a click, and keep terminals next to your conversations.

  • Reorder, rename and bookmark conversations
  • A tab shows when an answer is ready
  • Ctrl Shift P finds any tab in any group

A group for every project

Each group keeps its own tabs, panes and layout. Switching groups swaps the whole workspace in one click.

  • Website, research, server: each in its own space
  • Alt 1-9 jumps straight to a group
  • Terminals keep running while you are elsewhere

And more

Small details, all day long

A native app around the real ChatGPT and Claude pages. Nothing is re-implemented, so everything you have in the browser still works.

Terminal tabs

PowerShell on Windows, zsh on Mac, in a tab beside your chats.

ChatGPT and Claude

Use either or both, with your own accounts, plans and limits.

Knows when it is done

A ring while an answer is written, a dot and an optional chime when it is ready.

Private by design

No ChatDeck account, no servers, no tracking. Your chats stay with OpenAI and Anthropic.

Get started

Install in a minute

ChatDeck is new and not code-signed yet, so your computer asks once before the first launch.

  1. Download and run the installerNo administrator rights needed. It installs for you alone.
  2. If Windows says "Windows protected your PC"Choose More info, then Run anyway.
  3. Sign in to ChatGPT or ClaudeNew versions install from Settings inside the app.
  1. Open the dmg and drag ChatDeck to ApplicationsOne download for Apple Silicon and Intel Macs.
  2. Allow the first launchmacOS blocks it once: open System Settings › Privacy & Security and choose Open Anyway. If it says the app "is damaged", run xattr -dr com.apple.quarantine /Applications/ChatDeck.app in Terminal.
  3. Sign in to ChatGPT or ClaudeTo update, download the latest dmg from this page.
